# Essays

Long-form essays by Anubhav Adhikari, published with GitHub Pages.

## Adding a new essay

1. Copy the `not-the-final-form/` folder to a new folder named after the essay (e.g. `my-next-essay/`).
2. Replace the text and images inside its `index.html`.
3. Add an entry for it to the list in the root `index.html`.
4. Commit and push to `main`. The site updates within a minute or two.
